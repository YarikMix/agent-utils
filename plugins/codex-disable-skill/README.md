# codex-disable-skill

Скилл для отключения отдельных скиллов в Codex: убирает их из автокомплита
и автоматического выбора агентом через `enabled = false` в пользовательском
`config.toml`. Установленные файлы остаются на месте.

## Установка

```sh
codex plugin marketplace add YarikMix/agent-utils
codex plugin add codex-disable-skill@yarikmix-plugins
```

После установки перезапустите Codex.

## Использование

Попросите Codex отключить скилл по имени или укажите выбранную подсказку
на скриншоте. Для явного вызова: `$codex-disable-skill:codex-disable-skill`.
Если цель неоднозначна, агент уточнит её перед правкой.

Скилл сохраняет остальные настройки и проверяет результат записи.
После отключения перезапустите Codex для обновления автокомплита.
