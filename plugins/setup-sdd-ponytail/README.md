# setup-sdd-ponytail

Настройка глобальных инструкций для совместного использования Superpowers SDD
и Ponytail в Claude Code и Codex. Ponytail помогает выбрать простейшую реализацию
по согласованной спецификации, сохраняя обязательные этапы, артефакты,
согласования, тестирование и ревью SDD.

## Установка плагина

Claude Code:

```sh
claude plugin marketplace add YarikMix/agent-utils
claude plugin install setup-sdd-ponytail@yarikmix-plugins
```

Codex:

```sh
codex plugin marketplace add YarikMix/agent-utils
codex plugin add setup-sdd-ponytail@yarikmix-plugins
```

Установка добавляет скилл и сама по себе не меняет глобальные инструкции или память,
не устанавливает Ponytail и Superpowers и не запускает настройку автоматически.

## Вызов

Claude Code — `/setup-sdd-ponytail:setup-sdd-ponytail`.
Codex — `$setup-sdd-ponytail:setup-sdd-ponytail`.
Например: «Настрой глобальные инструкции для совместной работы Superpowers SDD и Ponytail».
Для чтения без правок: «Только проверь текущую настройку Superpowers SDD и Ponytail».
Обычная обнаружимость скилла сохраняется; обычные задачи SDD не требуют этой настройки.

Запрос «настрой» разрешает необходимые изменения в своей области без повторного
согласования. «Только проверь» и объяснение разрешают чтение и рекомендации.
При явном конфликте существующих пользовательских правил агент уточняет решение
до записи.

По умолчанию настраивается текущий клиент; другой или оба — только в пределах
запроса. **PAIW поддерживается, но не является зависимостью.** Агент использует
существующую подключённую глобальную память, иначе — действующие пользовательские
инструкции клиента. Наличие каталога памяти не доказывает её подключения.

Полное правило остаётся без изменений, частичное дополняется на месте;
соседний текст и ссылки сохраняются. Повторный запуск не создаёт дублей правила,
заметки или индексной ссылки. Управляемый или недоступный источник не обходится
новым override или затеняющей копией. Исходники, кэш и шаблоны обоих инструментов
не меняются.

Инструкции и полный текст правила: [SKILL.md](skills/setup-sdd-ponytail/SKILL.md).
Правило включает дословную передачу базового абзаца исполнителю и ревьюеру,
включая каждое задание исправления, вместе с путями согласованных спецификации
и плана; приёмку по требованиям и доказательствам обязательных проверок
в существующем цикле исправлений SDD.

## Проверка результата

После настройки агент перечитывает запись, показывает пути и краткое содержание
изменений. Загрузку обновлённых глобальных инструкций проверяют в **новой сессии**
клиента. Запись файла, загрузка инструкций и наблюдаемое соблюдение SDD — отдельные
результаты; текст правила не гарантирует его выполнение.

Проверены структура упаковки, manifests, регистрации marketplace, локальные ссылки
и frontmatter, а также синтетические сценарии записи на изолированных профилях.
Живая загрузка плагина и глобальных инструкций, а также выполнение реальной задачи
SDD не подтверждены. Native Claude Code не был залогинен; синтетические профили
Claude проверялись через Codex, что не доказывает поведение native Claude.
Подробности: [отчёт о проверках](../../docs/superpowers/research/2026-10-27-setup-sdd-ponytail-validation.md).
