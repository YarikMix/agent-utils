# Проверка и ограничения

Живая проверка 01.11.2026: macOS 26.7.1, физический Samsung SM-A175F, Android 16/API 36, экран 1080×2340, locale ru_RU; Node 24.21.0, Appium MCP 1.97.1, embedded UiAutomator2 8.7.0, appium-adb 16.1.0. Это одна проверенная комбинация, не минимальные требования.

Подтверждены через подключённый MCP:

- discovery выбранного USB-телефона, создание сессии с noReset и без автогранта разрешений;
- NATIVE_APP, PNG с просмотром и XML с чтением;
- поиск по resource-id, accessibility id и Android UiSelector, tap с проверкой перехода;
- точный ввод смешанной русской/латинской строки в пустом поиске Settings, очистка кнопкой поля, проверка placeholder и отсутствия тестового текста;
- scroll up/down с реальным смещением и возвратом, координатная прокрутка;
- Back, Home, activate Settings и восстановление раздела USB-отладки в «Параметрах разработчика», исходный NATIVE_APP сохранён.

Во время исходной проверки управления системные переключатели не менялись. Положение списка восстановлено приблизительно: строка USB-отладки оказалась на 23 px ниже исходной; это не точное пиксельное восстановление. Чужая история поиска сохранена.

Первоначальный `device unauthorized` устранён пользователем: на телефоне повторно включена USB-отладка, переподключён кабель и подтверждено доверие Mac. Режим «USB для зарядки» не был сам по себе доказательством запрета ADB. `scroll_to_element` с тремя короткими шагами корректно вернул «не найдено» до достижения цели; успешное нахождение этим action не проверено.

Не проверены: чистая установка на втором Mac, другие производители/ОС, эмуляторы, Wi-Fi ADB, WebView/Chromedriver, pinch/мультитач, восстановление после реального обрыва USB/stale session. Прикладные APK Почты/Облака в эту проверку не входили.

Отдельный Claude CLI для сценарного baseline завершился `Not logged in` до ответа модели. RED/GREEN и автоматическое обнаружение скилла этим клиентом не подтверждены; статический validator и проверка ссылок их не заменяют. Личные serial, пути, кадры и полный device-info в пакет не включаются.

Отдельно 01.11.2026 на этом Samsung по запросу пользователя включено «Не выключать экран» при зарядке. Подтверждены checked=true и PNG; read-only ADB показал stay_on_while_plugged_in=15, mIsPowered=true, mPlugType=1, mStayOn=true и mWakefulness=Awake. Тайм-аут на батарее остался 600000 мс. Длительное ожидание без ввода не проверялось; значение 15 — наблюдение этого телефона, не требование для всех Android.

Упаковка phone-control 1.2.0: оба клиента получают пять скиллов из одного каталога skills — iphone-control, android-control, setup-iphone-control, setup-android-control и setup-ios-sim. Отдельный плагин setup-iphone-control снят с каталогов; его три файла скилла перенесены без изменения содержимого.
Проверки JSON, frontmatter и локальных ссылок не заменяют discovery клиента.
Исходные Android-инструкции прошли read-only review схем MCP; reasoning review
не заменяет независимый RED/GREEN прогон.
