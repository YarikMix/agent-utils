# Karabiner Layout Switch

Скилл первоначальной настройки **Karabiner-Elements** для переключения английской
и русской раскладок по **Cmd + Shift** на macOS. Поддерживает встроенную клавиатуру
и **Keychron K8 Pro** по Bluetooth/USB, в том числе устройство, которое определяется
одновременно как клавиатура и мышь.

## Установка плагина

Claude Code:

```sh
claude plugin marketplace add YarikMix/agent-utils
claude plugin install karabiner-layout-switch@yarikmix-plugins
```

Codex:

```sh
codex plugin marketplace add YarikMix/agent-utils
codex plugin add karabiner-layout-switch@yarikmix-plugins
```

Затем попросите агента: «Установи Karabiner и настрой переключение английской
и русской раскладок по Cmd + Shift, включая Keychron K8 Pro».
В Codex скилл также вызывается как
`$karabiner-layout-switch:karabiner-layout-switch`, в Claude Code —
`/karabiner-layout-switch:karabiner-layout-switch`.

Установка плагина добавляет инструкции и вспомогательные скрипты, а не устанавливает
Karabiner автоматически. Установка Karabiner выполняется по запросу пользователя.

## Что сделает агент

- Установит Karabiner через имеющийся Homebrew или официальный установщик.
- Проверит доступ к GUI через Peekaboo MCP или CLI. При рабочем доступе настроит
  интерфейс; иначе выполнит доступные шаги через терминал и выдаст точные ручные
  инструкции. Peekaboo автоматически не устанавливается.
- Определит реальные включённые источники ввода: например, ABC/«Русская» или
  US/«Русская — ПК»; добавит правило в активный профиль с резервной копией.
- Включит обработку обнаруженной K8 Pro, не меняя остальные мыши и клавиатуры.
- Проверит службы и загрузку конфигурации; предложит физическую проверку клавиш.

Python 3.9+ нужен вспомогательным скриптам; сторонние Python-пакеты не нужны.
Пароль администратора и Touch ID вводит пользователь в системном окне macOS.
Наличие Peekaboo Desktop само по себе не гарантирует подключение к агенту и права.

## Поведение и ограничения

Обе стороны Cmd/Shift и оба порядка нажатия поддерживаются. Самостоятельное
сочетание переключает язык при отпускании второй нажатой клавиши; третья клавиша
отменяет переключение, поэтому **Cmd + Shift + Z** сохраняет своё действие.
Кнопка мыши, прокрутка и удержание более 60 секунд тоже отменяют переключение.
Проверка аппаратного перехвата выполняется физической клавиатурой.

Если K8 Pro не подключена, её обработку надо включить после подключения повторным
вызовом скилла. Существующая конфигурация сохраняется, повторный запуск не добавляет
дубликатов. Автоматический редактор отказывается переписывать JSONC с комментариями
и неоднозначно выбранный профиль. Punto и другие приложения сам не удаляет.

Вспомогательный редактор по умолчанию только показывает план. Пример команд,
резервное копирование и откат описаны в
[SKILL.md](skills/karabiner-layout-switch/SKILL.md); ручные шаги — в
[manual-setup.md](skills/karabiner-layout-switch/references/manual-setup.md).

## Проверки

Из корня репозитория:

```sh
python3 -m unittest discover -s plugins/karabiner-layout-switch/tests -v
```

Тесты конфигурации работают только во временных папках. Проверка чтения источников
ввода на macOS использует TIS API и ничего не меняет; на других ОС пропускается.
Для проверки синтаксиса правила установленным Karabiner можно сформировать конфиг
во временной папке, извлечь `complex_modifications.rules` в отдельный JSON с `title`
и передать его в `karabiner_cli --lint-complex-modifications`.
