# Cmd + Shift для переключения раскладки в macOS

Настрой Karabiner-Elements так, чтобы отдельное нажатие Cmd + Shift переключало английскую и русскую раскладки, а Cmd + Shift + Z и другие сочетания с третьей клавишей сохраняли своё действие и язык. Поддерживаются встроенная клавиатура и Keychron K8 Pro. Устанавливай и настраивай программу в рамках запроса пользователя; установленный скилл сам по себе не запускает настройку.

## 1. Проверь машину и доступ к интерфейсу

Проверь macOS, наличие Karabiner в `/Applications`, Homebrew и `python3`. Скриптам нужен Python 3.9+. Если Python отсутствует, установи через имеющийся Homebrew (`brew install python`); без Homebrew используй подписанный установщик с [python.org/downloads/macos](https://www.python.org/downloads/macos/). При доступном управлении установи сам с пользовательским подтверждением пароля; иначе дай указания из ручного сценария. Karabiner можно установить до Python, но применение конфигурации дождётся Python. Не устанавливай Homebrew или Xcode только ради этой настройки.

**Peekaboo необязателен для установки и записи конфигурации.** Проверь отдельно:

- Доступны ли агенту Peekaboo MCP tools; если нет, доступен ли CLI `peekaboo` и соответствующее локальное руководство.
- Есть ли соединение с приложением/host и разрешения для снимков и управления интерфейсом. Наличие Peekaboo Desktop.app не доказывает наличие работающего управления.
- Разрешает ли текущий инструмент требуемое действие: фоновые MCP tools могут наблюдать окно, но не запускать приложения или переводить их на передний план. Отказ инструмента не означает, что кнопка не нажата: перечитай состояние перед повтором.

При доступном управлении настрой интерфейс сам. Если инструмента, соединения или разрешения нет, продолжи доступные действия через терминал и дай точные инструкции по оставшимся шагам из [manual-setup.md](references/manual-setup.md). Не устанавливай Peekaboo автоматически. Пароли и подтверждение Touch ID пользователь вводит в системном диалоге; не считывай и не обходи их. Не меняй TCC-базу для выдачи разрешений.

## 2. Установи или проверь Karabiner

Если Karabiner уже установлен, используй его, не переустанавливай ради настройки. Иначе при наличии Homebrew:

```sh
brew install --cask karabiner-elements
```

Для установки без Homebrew используй текущий стабильный установщик с [официального сайта](https://karabiner-elements.pqrs.org/). Проверь подпись Developer ID и нотариальное заверение (`pkgutil --check-signature`, `spctl --assess --type install`); не отключай Gatekeeper. Не фиксируй версию на 16.3.0 из примера старой настройки. Если Homebrew скачал пакет, но `sudo` требует терминал/пароль, открой этот проверенный пакет системным Installer и дай пользователю подтвердить установку. Сообщай о появлении окон заранее.

Открой Karabiner Settings и выполни Setup: фоновые службы, Accessibility/Input Monitoring, Driver Extension. Названия меняются между версиями: ориентируйся на текущие подсказки. Тип виртуальной клавиатуры выбирай по аппаратным данным или форме Enter и левого Shift, а не по языку ввода: ANSI, ISO, JIS. Существующий выбор сохраняй.

## 3. Определи раскладки и клавиатуры

Пути ниже заданы относительно папки этого `SKILL.md`; найди абсолютный путь скилла в текущем плагине. Используй его в командах, не полагайся на текущий каталог проекта.

```sh
python3 scripts/input_sources.py
```

Скрипт только читает включённые источники через macOS TIS API. Выбери реальные ID английской и русской раскладок из результата. `ABC`, `US`, `Russian` и `RussianWin` различаются. Если подходящих вариантов несколько — уточни выбор; если раскладки нет, добавь её через системный интерфейс или дай инструкцию. Не подставляй несуществующий ID. При ошибке TIS API используй Variables в Karabiner-EventViewer для чтения ID; не считай пустой/ошибочный ответ подтверждением.

Штатный CLI установлен вместе с Karabiner:

```sh
karabiner_cli='/Library/Application Support/org.pqrs/Karabiner-Elements/bin/karabiner_cli'
"$karabiner_cli" --show-settings-window-guidance
"$karabiner_cli" --list-connected-devices
```

Если есть нестандартный путь, найди CLI в установленном приложении. Сохрани **успешный JSON-массив** `--list-connected-devices` во временный файл для следующего шага. Код возврата 0 с `asio.system` в stderr не является успехом. При отказе песочницы используй штатное разрешение на чтение состояния машины, не объявляй службы сломанными.

**Keychron K8 Pro может определяться одновременно как клавиатура и мышь.** Karabiner по умолчанию игнорирует мыши, поэтому общего правила недостаточно: включи `Modify events` именно у обнаруженной K8 Pro в Devices либо добавь для её фактических `device_identifiers` значение `ignore: false`. Для Bluetooth наблюдались vendor_id 13364, product_id 640; для USB идентификатор может отличаться — читай текущее устройство. Не включай обработку всех мышей и не меняй настройки YubiKey или других устройств.

Если Keychron не подключена, настрой встроенную клавиатуру и явно укажи, что поддержку внешней надо завершить после её подключения и повторного запуска скилла.

## 4. Добавь правило, сохранив настройки

Используй [scripts/configure.py](scripts/configure.py): по умолчанию он показывает план без записи, с `--apply` обновляет активный профиль. Пример **только для реально обнаруженных** ABC/Russian:

```sh
python3 scripts/configure.py \
  --english-id com.apple.keylayout.ABC \
  --russian-id com.apple.keylayout.Russian \
  --devices-json /absolute/path/to/observed-devices.json
```

Проверь результат и повтори ту же команду с `--apply`. `--keyboard-type ansi|iso|jis` заполняет только ещё не выбранный тип. `--config` позволяет явно указать конфигурацию; по умолчанию учитывается `XDG_CONFIG_HOME`, иначе `~/.config/karabiner/karabiner.json`. Сверь этот путь с тем, который реально загрузил Karabiner. Не запускай скрипт через `sudo`: пользовательский конфиг должен принадлежать пользователю.

Скрипт создаёт резервную копию исходных байтов и записывает файл атомарно; сохраняет остальные профили, правила и устройства; повторный запуск не добавляет дубликаты. Меняет своё правило и точные настройки обнаруженных K8 Pro. При некорректном JSON, комментариях JSONC или неоднозначном активном профиле остановись и исправь причину вместе с пользователем, сохранив исходный файл. Не заменяй весь конфиг шаблоном.

Правило использует `to_if_alone`: переключение при отпускании второй нажатой клавиши, отмена при третьей клавише, кнопке мыши или прокрутке. В `to` явно сохраняются оба модификатора. Покрыты левые/правые Cmd/Shift и оба порядка нажатия; источники выбираются напрямую. Удержание более 60 секунд переключение отменяет. Не заменяй `to_if_alone` на безусловный `to_after_key_up`, иначе сломаешь Cmd + Shift + Z.

## 5. Проверь и отчитайся

- `--show-settings-window-guidance`: нет ошибки разбора/прав, драйвер подключён, виртуальная клавиатура готова, фоновые службы включены и работают. На новых версиях имена полей могут отличаться — сверь по Setup.
- Журнал `/var/log/karabiner/core_service.log`: для встроенной и подключённой K8 Pro есть актуальное `hid device events monitor is started (grabbed)`, без последующего `stopped`/`terminated`. Наличие устройства в списке ещё не подтверждает обработку.
- Если доступен Punto, проверь конфликт двух переключателей. Установка Karabiner не разрешает автоматически удалять Punto: согласуй отключение его запуска отдельно, если оно ещё не разрешено пользователем.
- Попроси проверить физическими клавишами на каждой клавиатуре: Cmd + Shift в обоих порядках и с обеих сторон переключает язык один раз; Cmd + Shift + Z не меняет язык; обычные Cmd + C и Shift + буква работают. Программная имитация клавиш может обходить перехват Karabiner и не заменяет этот тест.

В отчёте разделяй: установка, запись настройки, готовность служб, подтверждённая пользователем работа клавиш. При ручных шагах перечисли оставшиеся действия и не объявляй всё готовым. Закрой только открытые тобой окна настройки, оставив фоновые службы работать. Дай путь резервной копии. Для отката восстанови её в тот же конфиг; если после настройки были другие правки, удали только своё правило и верни прежние значения `ignore`, не затирай новые изменения.
