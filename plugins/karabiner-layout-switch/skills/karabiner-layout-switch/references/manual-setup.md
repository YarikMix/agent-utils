# Ручные шаги без работающего Peekaboo

Давай только оставшиеся шаги, исходя из проверенного состояния. Сначала выполни установку и доступную конфигурацию через терминал. Не требуй ставить Peekaboo ради одноразовой настройки.

Если Python отсутствует и агент не может установить его сам: открой
[официальные установщики Python для macOS](https://www.python.org/downloads/macos/),
скачай актуальный стабильный Python 3, совместимый с твоей macOS, открой `.pkg`
и заверши установку. Открой новый терминал и проверь `python3 --version` — нужен
3.9 или новее. Передай результат агенту, чтобы он продолжил чтение раскладок
и применение правила. Установщик Python должен пройти обычную проверку macOS;
отключать Gatekeeper не требуется.

1. Открой **Karabiner-Elements → Setup**. Если установка ещё не завершена — открой скачанный официальный `.pkg` и подтверди установку паролем в macOS.
2. В **Системные настройки → Основные → Объекты входа и расширения** разреши фоновые службы Karabiner. В 16.3 они называются **Karabiner-Elements Non-Privileged Agents v2** и **Karabiner-Elements Privileged Daemons v2**.
3. В **Конфиденциальность и безопасность → Универсальный доступ** разреши **Karabiner-Core-Service**. Если Setup отдельно требует **Мониторинг ввода**, разреши указанный им компонент там. Подтверди пароль/Touch ID, если macOS попросит.
4. В **Основные → Объекты входа и расширения → Расширения** открой расширение **.Karabiner-VirtualHIDDevice-Manager** (либо раздел **Расширения драйверов**) и включи его. Нажми **Готово**. Ориентируйся на текущий Setup: расположение зависит от macOS и версии Karabiner. Перезагружайся только если это требует система, не инициируй перезагрузку вместо пользователя.
5. В **Virtual Keyboard** выбери физический тип: **ANSI** — обычный горизонтальный Enter и длинный левый Shift; **ISO** — высокий Enter и дополнительная клавиша рядом с коротким левым Shift; **JIS** — японская клавиатура. Язык «Русская» не означает ISO.
6. Подключи **Keychron K8 Pro**, открой **Devices** и включи **Modify events** у её строки. Если есть строки для разных транспортов, выбирай подключённую сейчас. Не включай обработку всех мышей. Если Cmd работает как Win/Alt, проверь физический переключатель Keychron **Mac/Windows** и системные настройки модификаторов.
7. Если нужных раскладок нет: **Системные настройки → Клавиатура → Ввод текста → Изменить → +**. Добавь выбранные английскую и русскую. Для нескольких вариантов передай агенту предпочтения.
8. Если агенту не удалось прочитать ID: открой **Karabiner-EventViewer → Variables**, выбери по очереди каждую раскладку в меню macOS и передай значения `input_source.input_source_id`. Не подставляй переведённое название вместо ID.
9. После применения конфигурации проверь физические **Cmd + Shift** и **Cmd + Shift + Z** на встроенной и внешней клавиатурах. Сообщи агенту результат для завершения проверки.

Если разработчик хочет настроить Peekaboo для последующих задач, направь к [официальному проекту](https://github.com/steipete/Peekaboo). Установленные CLI, Desktop/host и подключённые к конкретному агенту MCP tools — разные проверки. Нужные разрешения выдаются системным интерфейсом; установка приложения не гарантирует доступ к интерфейсу из текущей сессии.
