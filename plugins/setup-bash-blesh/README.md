# setup-bash-blesh

Настройка интерактивного Bash с ble.sh в Ubuntu под WSL по явному запросу разработчика.
Оболочкой остаётся Bash; ble.sh добавляет подсветку ввода, предложения из истории
и дополнений, принятие видимой подсказки клавишей Tab и обычное Bash completion.
Нейтральная подсветка неполной команды также отключает выделение остальных
синтаксических ошибок через `syntax_error`.

## Установка плагина

Claude Code:

```sh
claude plugin marketplace add YarikMix/agent-utils
claude plugin install setup-bash-blesh@yarikmix-plugins
```

Codex:

```sh
codex plugin marketplace add YarikMix/agent-utils
codex plugin add setup-bash-blesh@yarikmix-plugins
```

## Явный вызов

Claude Code — `/setup-bash-blesh:setup-bash-blesh`.
Codex — `$setup-bash-blesh:setup-bash-blesh`.
Например: «Настрой интерактивный Bash с ble.sh в Ubuntu под WSL».
Для проверки без правок явно попросите только исследовать текущую настройку.

Установка плагина добавляет инструкции и **сама по себе не меняет dotfiles**,
не устанавливает ble.sh и не запускает фоновую настройку. Разработчик вызывает
скилл вручную. Агент сначала исследует среду и предлагает конкретные изменения;
если тот же запрос уже явно поручает настройку, повторное разрешение не требуется.

Нужны Ubuntu, WSL и доступный Bash. Наличие VS Code или активного терминала
VS Code не требуется. При неподходящей среде скилл останавливается без изменений.
Установка ble.sh выполняется только для текущего пользователя; существующие
настройки сохраняются, правки получают приватные резервные копии, повторный вызов
не должен дублировать конфигурацию.

Переход новых терминалов удалённого Linux-окна VS Code на профиль Bash —
отдельно предлагаемый необязательный шаг. Он сохраняет остальные настройки
и комментарии JSONC; уже работающие терминалы не завершаются.
