# Figma Ops: проверка первой итерации

Статус: первая итерация завершена. Все задачи и завершающие исправления проверены, независимый scoped re-review закрыл оба итоговых замечания без новых дефектов.

## Реализованный объём

Новый автономный плагин `figma-ops` и совместимый `figma-lookup` поддерживают `doctor`, `inspect`, `search`, `comments`, `thread`, `export`, `fills`. REST CLI дополняет Figma MCP: ищет по содержимому, восстанавливает предков исходной ноды, сохраняет полные обсуждения, скачивает и проверяет экспорт и image fills. Все операции первой итерации читают данные; отправка комментариев и изменения макетов не реализованы.

Поиск имеет явные области файла, страницы и произвольного поддерева. Inline limit ограничивает показ, а `--output` сохраняет все совпадения. Фильтр по ответу возвращает всю ветку обсуждения. Комментарии и ноды сопоставляются по настоящему pin, с явным учётом неопределённого охвата. PNG проверяется по пикселям; запрошенный scale сам по себе не доказывает фактический размер 2×.

У каждого имени собственные manifests Claude/Codex, skill, references и runtime. Каталоги обоих marketplace обновлены. Установку из удалённого marketplace следует выполнять после публикации ветки; сейчас результат локальный.

## Проверки и границы

- На окончательном коде `2f4bf69`: независимый controller run `python3 -B -m unittest discover -s plugins/figma-ops/tests -v` — **116/116 tests, 4.094s, OK**. Проверены transport/auth/cache, обход нод и ancestry, полные обсуждения, экспорт и самостоятельная упаковка обоих имён.
- `git diff --check b671054..2f4bf69` — без замечаний. Проверка 60 публикуемых файлов plugins/docs по приватным идентификаторам live-файла и комментария — 0 совпадений.
- Packaging smoke: два отдельных plugin roots в путях с пробелами, без соседнего плагина; 14 операций с synthetic transport и 16 help-вызовов. Проверяются manifests, references и побайтовое равенство generated copies. Это не проверка discovery внутри живого хоста.
- Свежие native Codex agents выбрали ожидаемые действия в 6/6 canonical и 5/5 legacy сценариях. Старый baseline выбирал UI для некоторых задач, доступных через настроенный REST. Это поведенческие симуляции выбора инструментов, без исполнения команд или MCP.
- Живой REST: `doctor` прочитал `/me`; `thread` вернул корень и два ответа; `inspect` нашёл исходный INSTANCE и четырёх предков с локальным depth; ограниченный `search` просмотрел 351 ноду и сохранил все пять совпадений при inline limit=1.
- Живой PNG export scale=2 сохранил 720×1600, 873518 bytes; независимая проверка Pillow подтвердила RGBA и диапазон alpha 0..255. Приватные тексты, идентификаторы, адреса макета и сами assets в tracked документы не включены.
- Загрузка большой страницы дважды завершилась curl 28 через 35.03 секунды. Полный поиск всего живого файла не подтверждён; успешная проверка относится к явно выбранному поддереву.
- Выполнение проверено на Python 3.13.7. Совместимость синтаксиса всех 13 canonical/generated/sync modules с Python 3.10 проверена через AST; фактический запуск на Python 3.10 не выполнялся.
- Живой Claude CLI из песочницы вернул `Not logged in`. Повтор вне песочницы отклонён автоматическим approval review из-за возможной передачи локального плагина внешнему сервису без отдельного разрешения. Обходов не предпринималось. Живое discovery в Claude Code и Codex не проверено; файловая упаковка и native симуляции не заменяют эту проверку.

## Итоговое ревью

Все пять задач прошли task reviews. Итоговое ревью всей ветки обнаружило два Important дефекта: корректный крупный PNG отбрасывался лимитом анализа alpha; отдельные XML-кодировки SVG вызывали необработанный ValueError и прерывали пакет. Оба исправлены одной волной в `2f4bf69` с подтверждёнными RED/GREEN регрессиями. Независимый scoped re-review: **F1 ADDRESSED, F2 ADDRESSED; новых дефектов и наблюдений вне scope нет**.

Крупные PNG проверяются потоково с блоками до 64 KiB; при превышении бюджета анализа пикселей 64 MiB файл сохраняется с `alpha=unknown` и предупреждением. Ограничения проверки: 100MP и 8 MiB на строку; Adam7 также не получает подтверждения alpha. Регрессии проверяют сохранённые RGBA8 4096×4096 и RGBA16 image fill, некорректные/избыточные/обрезанные потоки и ограничение дополнительной памяти анализа. Плохой SVG с декларацией UTF-32, Shift_JIS или UTF-7 возвращает per-asset invalid_asset; следующая корректная нода сохраняется, CLI выдаёт JSON partial с counts 2/1/1.

## Принятые решения и цена ошибки

1. Python 3.10+ standard library и системный curl: установка без сборки и рабочий системный TLS в текущем окружении. Цена ошибки — замена transport с сохранением CLI-контрактов.
2. Только чтение в первой итерации, включая комментарии. Цена ошибки — операции записи появятся позже ожидаемого.
3. Самостоятельный legacy plugin содержит генерируемые copies canonical helpers/references. Цена ошибки — размер пакета и сопровождение синхронизации.
4. Локальные commits в отдельном worktree, без push, merge и глобальной установки. Цена ошибки — интеграция остаётся отдельным шагом.
5. Image fills поддерживают GIF/WebP сверх четырёх форматов export API; alpha остаётся unknown с предупреждением. Цена ошибки — сопровождение дополнительных валидаторов сигнатур.
6. После живого timeout добавлен явный `search --node`; timeout и retries не увеличивались. Цена ошибки — дополнительный selector в публичном CLI; непроверенный остаток файла остаётся видимым.
7. Замечание о 1058 строках compatibility duplication принято как компромисс самостоятельной установки: один maintained source, generator и equality tests. Цена ошибки — забытый sync и дополнительный размер доставки; проверка равенства обнаруживает расхождение.
