# Приёмка Peekaboo Control

Дата: 2026-10-19. Проверен документационный плагин `peekaboo-control` 1.0.0 на одном настроенном Mac: CLI 4.9.0, Desktop 4.9.5. Это наблюдавшаяся совместимость, не минимальные версии.

## Живая проверка

Все действия выполнены фактическими MCP tools в собственном временном AppKit-приложении: поле ввода, кнопка со счётчиком и прокручиваемый текст. Пользователь предупреждён о тестовом окне; чужие документы не использовались.

| Проверка | Результат |
| --- | --- |
| Явный MCP → Desktop Bridge | Проверено: работающий MCP запущен с `--bridge-socket`; дополнительный CLI handshake выбрал remote GUI host Desktop |
| Системные права через MCP | Screen Recording, Accessibility, Event Synthesizing: granted; grants не менялись |
| Свежее наблюдение точного окна | Проверено `inspect_ui` с PID/window и `fresh: true`; opaque IDs передавались буквально |
| Targeted click | Счётчик изменился с 0 на 1; первоначальный ответ был unconfirmed, действие не повторялось, эффект прочитан свежим наблюдением и подтверждён `verify_state` |
| Ввод уникальной строки | `type` с явным свежим snapshot и `clear: true`; точный AX value подтверждён `verify_state`, два стабильных образца |
| Прокрутка | MCP scroll down: scrollbar 0 → 0.5, текст сместился в AX; screenshot показал строки 30–51. Scroll up вернул 0 и видимые строки 1–22 |
| Дополнительная read-only CLI операция | `bridge status` с явным socket: success, Desktop handshake OK |
| Cleanup | Неоднозначный MCP close не повторялся; завершён только собственный fixture-процесс, отсутствие приложения проверено через MCP; временные данные удалены |

`verify_state` по имени приложения сначала вернул unknown из-за неполной инвентаризации других процессов; точный PID дал satisfied. Первый screenshot завершился timeout; после свежего наблюдения захват через поддерживаемый classic engine удался. Первоначальная AX-инвентаризация временного приложения была неполной; перед действиями получено полное свежее наблюдение точного окна. Эти ограничения не скрыты успешной отправкой событий.

Sandbox не разрешил CLI доступ к socket: это не отказ TCC или MCP policy. Та же read-only диагностика после адресного разрешения sandbox выполнилась успешно. MCP denial через CLI не обходился. Foreground, clipboard, конфиги и системные разрешения не менялись.

Переносимые диагностические команды, проверенные по leaf help и живому результату:

```sh
peekaboo bridge status --help
peekaboo bridge status --bridge-socket '<bridge-socket>' --json
```

Плагин публикует схемы MCP и общие правила действий, а не универсальные mutation-команды CLI. `see`, `select-text`, `set-value`, `mcp serve` проверялись по help; это подтверждает синтаксис, а не живую работоспособность всех режимов. Примеры конфигурации — структура для согласованной настройки, не испытанная установка другого клиента.

## Поведенческая оценка и упаковка

До написания навыка заморожены семь отложенных сценариев. В baseline пять прошли, один был частичным, один выявил пробел: конкретное разрешение foreground процесса MCP. Версия навыка до расширения карты операций по итогам финального ревью прошла 7/7; во всех семи свежих процессах проверено фактическое чтение текущего SKILL.md и релевантной справки. Baseline-успехи являются регрессионными проверками, а не улучшением.

Обычный Claude CLI оказался unauthenticated, поэтому с явного согласования использован свежий Codex. Полный Claude-прогон не заявляется. В окружении были предупреждения model-list timeout и существующих agent-role конфигураций; прогон не считается запуском на чистом окружении.

Проверены validator навыка, JSON manifests/marketplaces, уникальность записи плагина, локальные ссылки и `git diff --check`. После финального ревью расширена карта operations.md: capture, Spaces, Dock, анализ изображения, lifecycle, browser/agent routing и CLI-семейства. Имена и ограничения сверены с сохранённым catalog, текущими описаниями MCP и локальным CLI help. Выполнен свежий адресный повтор прежнего сценария D (read-only CLI capability diagnostics): успешное чтение точного текущего SKILL.md и изменённого operations.md подтверждено trace; ответ сохраняет explicit socket, leaf help и границы доказательств. Полный набор A–G и GUI-приёмка после расширения не повторялись; прежние 7/7 не доказывают все добавленные режимы. Validator, затронутые локальные ссылки, privacy scan и diff check повторены.

## Границы доказательств

Чистый второй Mac, установка и полный запуск в Claude Code, foreground/temporary clipboard grants и остальные mutation-режимы CLI не проверены. Добавленные capture/live/video, Spaces, Dock, analyze, lifecycle и browser/agent маршруты проверены документально; живой эффект этих режимов не подтверждён. Проверка описывает перечисленные операции одного настроенного Mac. Публикация и установка из опубликованного SHA подтверждаются отдельно после независимого ревью.
