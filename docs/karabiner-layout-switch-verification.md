# Karabiner Layout Switch 1.0.0: границы и проверка

## Согласованный результат

Скилл для Claude Code и Codex устанавливает Karabiner по запросу пользователя,
настраивает Cmd+Shift для выбранных английской и русской раскладок и поддерживает
Keychron K8 Pro. Рабочий Peekaboo позволяет автоматизировать интерфейс; без него
агент продолжает действия через терминал и передаёт только оставшиеся ручные шаги.
Peekaboo автоматически не устанавливается. Пароль/Touch ID подтверждает пользователь.
Punto не удаляется без отдельного запроса.

Выбор реализации: Python со стандартной библиотекой для чтения TIS API и безопасного
слияния конфигурации; манифесты и регистрация в обоих маркетплейсах репозитория.

## Проверено

- 13 unittest-проверок: preview без записи, точная резервная копия, сохранение чужих
  правил/профилей/устройств/типа клавиатуры, повторное применение без дублей,
  16 вариантов правила, реальные ID раскладок, Bluetooth/USB product_id из наблюдения,
  отказ при ошибочных входах, чтение настоящих источников macOS.
- Правило для US/RussianWin принято штатным
  `karabiner_cli --lint-complex-modifications`.
- `quick_validate.py` принял SKILL.md; `claude plugin validate` принял манифест.
- Оба каталога ссылаются на существующий плагин, версии совпадают,
  путь к скиллу разрешается внутри пакета.
- Независимый прогон скилла на временной конфигурации подтвердил сохранение исходных
  настроек, отсутствие дублей, точечный `ignore:false` для комбинированной K8 Pro
  и корректное поведение при её отключении. Отсутствие MCP не было принято за
  наличие автоматизации только потому, что установлен Peekaboo Desktop.
- Независимое ревью не обнаружило дефектов в проверенных сценариях.

До написания скилла контрольный ответ без него предложил общее правило для клавиатур,
но не включил `ignore:false` у комбинированной K8 Pro. Именно эта пропущенная настройка
выделена в скилле и закреплена проверкой конфигурации.

## Ограничения проверки

На машине автора не переустанавливались приложения, не менялись разрешения
и рабочий конфиг Karabiner. Свежая установка macOS, установка плагина в оба клиента,
физическая USB K8 Pro и все перестановки нажатий этим прогоном не проверены.
Поведение `to_if_alone` опирается на документацию Karabiner и рабочую настройку,
подтверждённую пользователем ранее; оно не доказывается Python-тестами.
Финальный аппаратный тест и запуск после входа в macOS описаны в скилле.
